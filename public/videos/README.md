# Assets pendientes

Este proyecto referencia los siguientes archivos, que aún no existen y deben añadirse antes de publicar:

- `public/videos/dora-electroservices.webm`
- `public/videos/dora-electroservices.mp4`
- `public/images/dora-video-poster.webp`

Especificaciones: fuente horizontal 16:9, versión mobile optimizada recomendada, poster en WebP/AVIF
(< 150 KB en móvil, < 300 KB en desktop). Ver `components/video/ScrollPanVideo.tsx`.

Mientras estos archivos no existan, el navegador mostrará el `poster` (si se añade) o un recuadro vacío;
no se debe "simular" un video funcionando.
